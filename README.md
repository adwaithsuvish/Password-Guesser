# Common Password Generator 


This programs generates the most common password by using the personal information given by the user. This program uses basic permutation functionality to the program.The program creates a text file with the passwords

It is created using python loops and file functions. Run the main.py to create the file.

This program can be used for checking the strength of your passwords.

This program is not completed and hs more possible passcode to be added.

*This program does not store any personal information*
